# תיקיית תמונות מדור קודם

⚠️ **תיקייה זו לא בשימוש יותר**

התמונות עכשיו מנוהלות דרך:
- **Google Drive** - אחסון הקבצים
- **Google Sheets** - מידע ופרטים
- **פאנל הניהול** - ממשק ניהול

## מה קרה לתמונות הקיימות?

התמונות שהיו בתיקייה זו עברו מיגרציה אוטומטית לגיליון `GalleryImages` ב-Google Sheets.

הקבצים עצמם נשארים כאן לצורך גיבוי, אבל המערכת כבר לא משתמשת בהם.

## איך להוסיף תמונות חדשות?

עבור לפאנל הניהול → **תמונות → ניהול תמונות**

קרא את `SETUP_INSTRUCTIONS.md` להוראות מפורטות.

---

**💡 טיפ:** אפשר למחוק את התיקייה הזו אם כל התמונות כבר ב-Drive ועובדות.
